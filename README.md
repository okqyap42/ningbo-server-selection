## 宁波机房专项：线路、稳定性与防御口径

**宁波是电信单线，不是 BGP。** 这点要提前知道：电信用户访问最顺，联通和移动用户的实际体验取决于你所在地区和运营商互联质量，别人说快不代表你那里快。雨云的官方区域指南对宁波的定位是“已有备案域名、面向国内用户、需要大带宽、稳定性要求高”。

在官方给出的几组排序里，宁波的位置很清楚：

- 网络稳定性：**宁波第一**，之后是十堰、宿迁
- 公网带宽大小：国内机房中宁波最大，仅次于洛杉矶 1 区
- 响应速度：宿迁最快，十堰和宁波基本持平，排在第三
- 防御能力：洛杉矶 2 区 > 宿迁 > 宁波 > 十堰 > 洛杉矶 1 区 > 香港

**防御这块有两个口径。** 区域指南写的是“浙江宁波：电信单线带 100G 高防”“可选择 100G 防御”，而 14900K 两档的套餐表标的是 10G。合理的解释是基础防御 10G、需要时升配到 100G，但两份资料的表述确实不一致。下单时请在配置页看清防御档位和对应价格，别默认 100G 是标配。

带宽方面，宁波支持流量计费模式，最低配置就能拿到 100Mbps 上下行。这种模式的代价是月流量有额度，超了要买流量包，跑下载站、做视频分发这类业务要先把流量成本算进来。

两个限制顺便记住：国内主机做网站必须先备案，只跑数据库、学习研究这类用途不需要独立 IP 也不用备案；另外宁波**不支持 macOS 镜像**，能装 macOS 的只有香港二区、香港四区和湖北十堰。

独立 IP 那 150 元/月是否跟着年付折扣一起打折，结算页会显示；按不打折估，就是上面这个数。4核16G 那档年付 7 折是 350 × 12 × 0.7 = 2940 元，折合 245 元/月。

**所以先想清楚你要不要独立 IP。** 开小服给熟人玩，NAT 映射端口完全够；要对外拉人、要让玩家直接填 IP 连进来，独立 IP 基本躲不掉。这一项决定了总价是接近 1100 还是接近 2900。

计费方式也会影响账单。固定计费是月租写死，CPU 跑满或空转一个价，适合玩家随时可能上线的中大型服。动态计费基础租金低，CPU 使用率超过 20% 的部分按“CPU 电量”日结加收，1 CPU 电量约等于 30% CPU 跑 1 分钟，单价大致 0.0005 到 0.001 元，系统每天还送一定免费电量。白天没人、晚上开几小时的服，动态计费能省下明显一截；24 小时不间断有人、CPU 长期高负载的服，动态反而更贵。

## 宁波、宿迁、十堰怎么选

不用把七个机房全看一遍，按需求对号入座：

**要稳定性，用户主要在华东，能接受电信单线** → 宁波。稳定性排序第一，国内带宽最大，浙江本地延迟有优势。

**怕被打，防御优先级最高** → 宿迁。京东云 BGP 线路，公网独享 150G 防御，防御能力排在宁波前面。BGP 线路对三网用户更友好，代价是带宽不如宁波。

**要电信单线 + 100G 防御 + 更低预算** → 十堰。同样是电信单线带 100G 高防，流量计费模式下最低配置有 50Mbps 上行、100Mbps 下行。响应速度和宁波差不多，稳定性略低一点。

**用户以联通、移动为主** → 优先考虑宿迁这类 BGP 节点，宁波的电信单线在这类用户身上不一定占优。

**预算卡得很死，只是练手** → 深圳或宿迁的入门档，或者直接上通用云服务器的 1核1G。

一句话规则：**稳定和大带宽选宁波，扛攻击选宿迁，想省钱又要高防选十堰，三网通吃选宿迁。**

## 哪些情况不适合选宁波

**要求正式 SLA 的企业核心业务**，雨云不是为这个场景设计的。第三方测评普遍提到它主打性价比路线，节假日高峰期偶有网络波动，关键业务最好自备冗余。

**用户主要在欧美**，也不合适。洛杉矶到大陆延迟在 150~250ms，反过来国内到美国同样不低；服务欧美用户应该选当地节点。

**离不开英文文档和英文客服**的团队要谨慎，它的文档和客服以中文为主。

**需要 macOS 镜像**的，宁波装不了。

**做网站但不打算备案**的，国内节点走不通，得看香港或日本。

**用户以联通、移动为主又要求三网质量一致**的，宁波的电信单线不合适，去看 BGP 线路的节点。
